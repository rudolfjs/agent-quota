## 0.4.0 - 2026-11-10
### Fixed
* Claude weekly limits now follow the usage API's `limits` list, so the model-specific weekly limit (for example Fable) is shown as `seven_day_<model>` and the stale "Sonnet" row no longer appears when the API reports no Sonnet window.
### Security
* Build releases with Go 1.27.3 and update golang.org/x/text to v0.41.0, fixing known vulnerabilities in the Go standard library and x/text.

> Update with `aq self-update` on Linux x86_64 and macOS (Intel and Apple Silicon).
