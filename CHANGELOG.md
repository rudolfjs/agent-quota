## 0.3.0 - 2026-10-09
### Added
* Read Claude, Codex, and Copilot CLI credentials from macOS Keychain; ship Intel and Apple Silicon Mac archives with installer and self-update support.
* Add `aq uninstall` to remove the binary, the `aq` shortcut, and agent-quota config on Linux and Mac, leaving provider credentials untouched.
### Changed
* Dependapot changes to bypass change fragment requirements
* Change the project license from Apache-2.0 to MIT.
### Fixed
* Keep the aq installer shortcut working with relative installation paths and make the short command prominent in installation guidance.
* Correct macOS Keychain authentication error handling and honor the current Copilot plaintext-storage setting in settings.json.
* Honor Codex credential storage settings, keep Claude file fallback in the selected profile with CLI-compatible Keychain accounts, and preserve Linux Copilot file authentication when macOS settings are invalid.

> Update with `aq self-update` on Linux x86_64 and macOS (Intel and Apple Silicon).

## 0.2.0 - 2026-05-20
### Removed
* Remove Gemini provider — gemini OAuth quota tracking is no longer supported. Existing settings.json or config.json entries referencing gemini are silently dropped on next launch.

> Update with `aq self-update` on Linux/amd64.


## 0.1.0 - 2026-05-04
### Added
* New `agent-quota` CLI tracks AI provider OAuth subscription quotas — pretty TUI for humans, headless JSON for scripts and agents
* New `claude` provider tracks Claude Code subscription quotas — 5-hour, weekly, and weekly-Sonnet windows
* New `copilot` provider shows GitHub Copilot usage and premium request quotas
* New `gemini` provider tracks Gemini Code Assist daily quotas via the `gemini` CLI's OAuth credentials
* New `openai` provider tracks ChatGPT Codex usage
* New TUI dashboard renders provider usage as scrollable cards with budget guide markers
* `--json` flag and `aq status` produce one-shot JSON output for scripts and agents
* New `aq` short alias — installer symlinks `aq` → `agent-quota`
* New `aq self-update` — atomic updates with sha256 verification (Linux/amd64)
* New `scripts/install.sh` one-line installer for prebuilt Linux/amd64 releases
* Persistent dashboard settings save shown providers, card order, header visibility, and refresh interval
* Dashboard auto-refreshes on a configurable interval — `Ctrl+R` forces immediate refresh

> Update with `aq self-update` on Linux/amd64.
